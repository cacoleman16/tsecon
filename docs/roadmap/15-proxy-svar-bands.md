## Why this exists

`proxy_svar` returns a point estimate and no interval. The
[interval-coverage audit](../examples/interval-coverage.md) makes the cost
concrete: it is the difference between an estimate a reader can weigh and one
they must take on faith. The obvious fix — the wild bootstrap used by
Mertens-Ravn (2013) and Gertler-Karadi (2015) — is **invalid** for this
estimand, which is the point of Jentsch-Lunsford (2019).

## Verified numerically before implementation

Four load-bearing claims were checked against synthetic data with a known
proxy rather than taken on trust:

| # | Claim | Result |
|---|---|---|
| 1 | A common Rademacher draw applied to residuals *and* proxy leaves `sum_t m*_t u*_t'` unchanged, so the wild bootstrap gives the identifying moment **no** variability | **Confirmed** — 200/200 draws bit-identical, max deviation exactly `0.000e+00` |
| 2 | Centering resampled residuals by the **grand** mean is a silent no-op (OLS with an intercept forces `sum_t uhat_t = 0`) | **Confirmed** — `max abs(mean(uhat))` = `1.5e-16` |
| 3 | **Position-wise** block means are *not* zero, so that fix has content the grand mean does not | **Confirmed** — `max abs(ubar_s)` = `4.19e-02`, ~7.1% of the residual sd, fourteen orders of magnitude above the grand mean |
| 4 | Independent block indices for `u` and `m` collapse the identifying moment toward zero | **Confirmed** — mean `gamma*[norm_var]` `+0.0006` vs sample `+0.5557`; the denominator changes sign in **50.7%** of draws (0.0% under joint blocking) |

Claim 1 is the decisive one: it is why `bands="wild"` must be reachable but
labelled, never the default. Claim 3 is the subtle one — an implementer who
"adds centering" using the grand mean ships a no-op that looks correct.

Reproduce: the check is a standalone NumPy script; see the table above for the
expected values.

## A. Moving-block bootstrap (Jentsch-Lunsford)

**Method.** Moving-block bootstrap (MBB) for proxy SVARs / SVAR-IV — the Jentsch–Lunsford bootstrap

**Citation.** PRIMARY: Jentsch, Carsten, and Kurt G. Lunsford (2019), "The Dynamic Effects of Personal Income Tax Changes on Macroeconomic Aggregates: A Reassessment," American Economic Review 109(7): 2655–2678. THEORY: Jentsch, Carsten, and Kurt G. Lunsford (2022), "Asymptotically Valid Bootstrap Inference for Proxy SVARs," Journal of Business & Economic Statistics 40(4) (earlier as Federal Reserve Bank of Cleveland Working Paper 16-19, rev. 2019/2021) — volume/page details UNVERIFIED, see `uncertain`. FOUNDATION for the VAR-side MBB: Brüggemann, Ralf, Carsten Jentsch, and Carsten Trenkler (2016), "Inference in VARs with time varying volatility...," Journal of Econometrics 191(1): 69–85 (exact title UNVERIFIED); Künsch, H. R. (1989), "The Jackknife and the Bootstrap for General Stationary Observations," Annals of Statistics 17(3): 1217–1241. WHAT IT REPLACES: Mertens, Karel, and Morten O. Ravn (2013), AER 103(4): 1212–1247; Gertler, Mark, and Peter Karadi (2015), AEJ:Macro 7(1): 44–76. COMPLEMENT (weak-IV): Montiel Olea, Stock, and Watson (2021), Journal of Econometrics.

**Stated confidence.** Medium-high overall, with the load-bearing parts stronger than the peripheral ones. I am confident (and the arithmetic is self-verifying) about: the joint (uhat_t, m_t) block as the resampling unit and why independence destroys identification; the recursive reconstruct-and-reestimate design with the actual presample values as initial conditions and no burn-in; position-specific (Künsch/BJT) centering as the end-effect correction and the fact that grand-mean centering is a no-op; the mandatory per-draw re-imposition of the unit-effect normalization and its exact degeneracy tell; and the reason the joint-Rademacher wild bootstrap is invalid (m*_t u*_t' = m_t uhat_t' pointwise, so the identifying moment carries no bootstrap variability) with under-coverage as the symptom. I am less confident about the block-length constant (5.03 T^{1/4}), the Hall-vs-Efron recommendation, and the exact form of JL's proxy rescaling — see `uncertain`. Critically, the rescaling uncertainty is contained: any positive scalar on m* cancels in rho*, so it cannot affect the IRF bands.

### Algorithm

1. SETUP AND NOTATION. Reduced form: y_t = nu + D d_t + sum_{i=1..p} A_i y_{t-i} + u_t, y_t in R^n, deterministic regressors d_t (constant, optional trend). Fit by OLS on the effective sample t = 1..T (T = n_obs - p). Store: coefficient set Ahat = (nuhat, Dhat, A1hat..Aphat); residuals uhat_1..uhat_T; Sigmahat_u; the MA matrices Psihat_0..Psihat_H (Psi_0 = I, Psi_h = sum_{i=1..min(h,p)} Psi_{h-i} A_i); and the p ACTUAL presample rows y_{1-p}..y_0. Proxy m_t in R^k aligned to the same effective sample t = 1..T, NaN where the instrument is unavailable. Point estimate (as already implemented in crates/tsecon-ident/src/proxy.rs): gammahat = mean over the finite-proxy overlap O of (m_t - mbar_O)(uhat_t - ubar_O)'; rhohat = gammahat / gammahat[norm_var]; bhat = unit * rhohat; thetahat_h = Psihat_h bhat, so thetahat_0[norm_var] = unit exactly.

2. STEP 1 — FORM THE JOINT RESAMPLING UNIT. Build the T x (n + k) matrix of PAIRS z_t = (uhat_t', m_t')', t = 1..T. This single stacked object is the resampling unit. Every block draw below indexes z_t, i.e. the SAME block start is applied to the residual columns and the proxy columns simultaneously. Never draw separate indices for uhat and m, and never leave m at its original (unresampled) values while resampling uhat. The whole identification is gamma = E[m_t u_t'] = H E[m_t eps_t] = phi * h_col, a CONTEMPORANEOUS cross-moment between the two blocks of z_t; the bootstrap must reproduce the sampling variability of that cross-moment, which requires the time-t pairing to survive resampling intact.

3. WHAT BREAKS IF THEY ARE RESAMPLED INDEPENDENTLY (state this in the code comment). If u and m get independent block indices (or m is not resampled at all), then in the bootstrap DGP m*_t and u*_t are independent, so the bootstrap population value of the identifying moment is E*[m*_t u*_t'] = E*[m*] E*[u*]' = 0 after centering. The bootstrap then draws from the distribution of gammahat UNDER THE NULL OF ZERO RELEVANCE: gamma* is O_p(T^{-1/2}) noise centered at zero, gamma*[norm_var] crosses zero constantly, and rho* = gamma*/gamma*[norm_var] is a ratio of two mean-zero noise terms, i.e. Cauchy-like with no finite moments. The bands are then not 'a bit wrong' — they are the wrong object entirely.

4. STEP 2 — BLOCK LENGTH AND BLOCK COUNT. Choose ell with 1 <= ell < T and (T - ell + 1) >= 2. Default: ell = round(5.03 * T^{1/4}) (Jentsch–Lunsford's rule; for quarterly macro T ~ 225 this gives ell ~ 19-20, about five years — the constant and exponent are flagged in `uncertain`). Requirement on the rate: ell -> infinity and ell/T -> 0 as T grows. Set N = ceil(T / ell) blocks. Blocks are drawn from the T - ell + 1 OVERLAPPING candidate blocks with starting indices 1..T-ell+1 (this is the moving-block bootstrap; do NOT restrict to the floor(T/ell) disjoint blocks).

5. STEP 3 — PRECOMPUTE THE END-EFFECT (POSITION-WISE) CENTERING TERMS. Because the candidate blocks overlap, an observation near t = 1 or t = T appears in strictly fewer candidate blocks than an interior observation, so the naive block bootstrap does NOT satisfy E*[u*_t] = 0 even though sum_t uhat_t = 0 by OLS. The standard Künsch/Brüggemann–Jentsch–Trenkler fix, which is what JL use, is position-specific centering: for each within-block position s = 1..ell compute ubar_s = (1/(T-ell+1)) * sum_{i=1..T-ell+1} uhat_{i+s-1}, and analogously mbar_s = mean over the same candidate starts of m_{i+s-1} (averaging only over finite proxy entries and tracking the count). NOTE: centering by the GRAND mean of uhat is a silent no-op (it is exactly zero by OLS with a constant) — the whole content of this step is that the mean is taken ACROSS CANDIDATE BLOCKS AT A FIXED WITHIN-BLOCK POSITION, not across time.

6. STEP 4 — PER-REPLICATION BLOCK DRAW (r = 1..B; B >= 2000 for 90% bands, more for 95%). Draw i_1..i_N i.i.d. Uniform{1, ..., T-ell+1}, independently and WITH replacement. For j = 1..N and s = 1..ell, let t = (j-1)*ell + s; stop once t > T. Set u*_t = uhat_{i_j+s-1} - ubar_s and m*_t = m_{i_j+s-1} - mbar_s, using the SAME i_j for both. Propagate NaN: if the source proxy entry is NaN, m*_t is NaN (the instrument's availability pattern is itself resampled, which is correct — the number of informative proxy observations should vary across draws). Truncate the concatenation to exactly T observations; for the final, partially used block only the positions actually used are centered.

7. STEP 5 (OPTIONAL, IRF-IRRELEVANT) — PROXY SCALE CORRECTION. JL apply a deterministic scale adjustment to the resampled proxy in addition to the centering; I cannot state its exact algebraic form from memory (see `uncertain`). CRITICAL DE-RISKING FACT: multiplying the entire bootstrap proxy m* by ANY positive scalar leaves rho* = gamma*_j / gamma*_{norm} exactly invariant, because the scalar appears in numerator and denominator alike. Therefore no choice here can corrupt the IRF bands; it can only change the reported bootstrap first-stage F* and reliability*. Implement the bands first, verify them, and treat the scale factor as a diagnostics-only refinement to be pinned from JL's replication code.

8. STEP 6 — RECURSIVE (REESTIMATION) DESIGN: RECONSTRUCT y*. This bootstrap is a recursive/residual-based design, NOT a fixed design. Initialize y*_{1-p}..y*_0 to the ACTUAL observed presample rows y_{1-p}..y_0 — no random block for the initial conditions and NO burn-in / discarded observations. Then for t = 1..T: y*_t = nuhat + Dhat d_t + sum_{i=1..p} Ahat_i y*_{t-i} + u*_t, keeping the deterministic regressors d_t at their ACTUAL dated values (same trend/constant design matrix as the original fit). Rationale for no burn-in: burn-in would simulate from the stationary distribution of the ESTIMATED VAR, which is ill-defined and numerically explosive when the estimated system has roots near unity (the tax and monetary VARs this method is used on do), and it would change what the bootstrap distribution is conditional on.

9. STEP 7 — REESTIMATE ON THE BOOTSTRAP SAMPLE. Refit the identical VAR specification by OLS on (y*_{1-p}..y*_0 as presample, y*_1..y*_T as the effective sample), obtaining Ahat*, residuals uhat*_1..uhat*_T, Sigmahat*_u, and MA matrices Psihat*_0..Psihat*_H. Use plain OLS (no bias correction, no stationarity screening) — this is what makes the bootstrap replicate the estimator's finite-sample behavior. Do not screen out explosive Ahat* draws; do guard against overflow so a draw with an explosive root produces large-but-finite Psi*_h rather than an inf/NaN crash.

10. STEP 8 — BOOTSTRAP IDENTIFYING MOMENT. Compute gamma* using the RE-ESTIMATED residuals paired with the resampled proxy: O* = {t in 1..T : m*_t finite}; gamma* = (1/|O*|) * sum_{t in O*} (m*_t - mbar_{O*}) (uhat*_t - ubar_{O*})'. Note uhat*_t is NOT u*_t (uhat* are OLS residuals from the bootstrap sample); the pairing between m*_t and uhat*_t nonetheless holds because uhat*_t = u*_t + O_p(T^{-1/2}) at the same date t. Require |O*| >= 3 and nonzero proxy variance over O*; otherwise mark the draw FAILED (do not silently skip — see Step 11).

11. STEP 9 — RE-IMPOSE THE UNIT-EFFECT NORMALIZATION INSIDE EVERY DRAW. This is mandatory, not cosmetic. Compute rho* = gamma* / gamma*[norm_var] and b* = unit * rho*, exactly as the point estimate does. The normalization (both SCALE and SIGN) is part of the definition of the estimand, so the bootstrap must apply the same map to each draw's moments. Consequences to expect and NOT to suppress: (a) b*[norm_var] = unit EXACTLY in every draw, so the h = 0 band for norm_var is degenerate at `unit` (zero width) — that is correct, and it is the cheapest available test that this step was implemented; (b) when gamma*[norm_var] is small the ratio has heavy tails, and when it changes SIGN the whole IRF flips — dividing by a negative gamma*[norm_var] flips every element so that the norm_var impact is again +unit, which is the correct handling. Do NOT apply any ad-hoc sign-fixing rule (e.g. forcing sign(gamma*_j) or the sign of some response to agree with the point estimate): that truncates one lobe of a genuinely bimodal distribution. If gamma*[norm_var] is exactly zero (or below a tiny absolute tolerance), mark the draw FAILED.

12. STEP 10 — BOOTSTRAP IRF AND DIAGNOSTICS PER DRAW. theta*_{h,r} = Psihat*_h b*, h = 0..H. Also store, per draw: gamma*[norm_var], the bootstrap first-stage F*, reliability*, and rho*. The gamma*[norm_var] distribution is the fragility diagnostic — if it comes close to zero the unit-effect object itself is badly behaved and you should be reporting weak-IV-robust bands (Montiel Olea–Stock–Watson 2021) instead of, or alongside, MBB bands.

13. STEP 11 — FAILED DRAWS ARE REPORTED, NOT HIDDEN. Record NaN for a failed draw's theta* row, count failures by reason, and expose the count. Silently discarding failures is a real bias: the failing draws are exactly the ones with a near-zero denominator, i.e. the extreme tails of the ratio distribution, so dropping them shrinks the interval. If failures exceed ~1% of B, emit a warning that the bands are not trustworthy at this instrument strength.

14. STEP 12 — CONSTRUCT THE INTERVAL. Recommended: Hall's percentile (a.k.a. basic / reverse-percentile) interval, which reflects the bootstrap DEVIATIONS around the point estimate rather than using the bootstrap quantiles directly. For each cell (h, i) and nominal level 1 - alpha: let q_a = the a-quantile of {theta*_{h,i,r} - thetahat_{h,i}} over the non-failed draws; then L = thetahat_{h,i} - q_{1-alpha/2} and U = thetahat_{h,i} - q_{alpha/2} (equivalently L = 2*thetahat - Q_{1-alpha/2}(theta*), U = 2*thetahat - Q_{alpha/2}(theta*)). ALSO compute and expose the Efron percentile interval [Q_{alpha/2}(theta*), Q_{1-alpha/2}(theta*)] for comparison, since it is what Mertens–Ravn / Gertler–Karadi report and the two differ materially when the bootstrap distribution is skewed or biased. My recollection is that JL recommend the Hall form specifically because block-bootstrap draws are not centered at the point estimate; this is flagged in `uncertain`. Do NOT report a normal-approximation interval thetahat +/- z * sd(theta*) and do NOT report a delta-method interval.

15. STEP 13 — REPORT BLOCK-LENGTH SENSITIVITY. Recompute the bands at ell/2, ell, and 2*ell (rounded, all < T) and report them. Bands should move smoothly and modestly; a discontinuous jump indicates a bug in the block construction or truncation, and a strong monotone trend in width indicates ell is in the wrong regime for this T.

16. STEP 14 — RNG DISCIPLINE. One seeded stream, advanced once per replication; draws must be reproducible bit-for-bit at a fixed seed and independent across replications. Block starts are drawn WITH replacement within a replication.

17. MULTI-INSTRUMENT NOTE (k > 1). The structure generalizes: the block unit is still (uhat_t', m_t')' with the same block starts, gamma* becomes n x k, and the normalization step inverts the k x k sub-block corresponding to the k normalizing variables (the Mertens–Ravn system) inside each draw. Everything about joint blocking, centering, recursive reestimation, and per-draw normalization carries over unchanged; JL's exact treatment of the k > 1 normalization is flagged in `uncertain`.

### What a wrong implementation does (these become tests)

1. INDEPENDENT BLOCK INDICES FOR u AND m (or the proxy left unresampled and paired with reestimated residuals from a reshuffled series). This is the most damaging and most likely bug. Symptoms, all checkable: median bootstrap first-stage F* collapses toward its null value ~1 instead of sitting near the sample Fhat; the distribution of gamma*[norm_var] is centered at zero rather than at gammahat[norm_var]; rho* is Cauchy-like so the 90% bands are orders of magnitude too wide and roughly symmetric about zero no matter where thetahat is; MC coverage goes to ~100% (vacuous) at every horizon; and — the giveaway — band width does NOT shrink at rate T^{-1/2} as T grows in the MC.

2. PER-DRAW NORMALIZATION NOT RECOMPUTED — i.e. using b* = (unit/gammahat[norm_var]) * gamma* instead of unit * gamma*/gamma*[norm_var]. Exact tell: the h = 0 band for norm_var is NON-degenerate (it must be exactly [unit, unit]); you will see a small but nonzero interval there. Direction of the coverage error is instrument-strength-dependent and this is worth stating in the docs: with a STRONG proxy the bands come out TOO WIDE and over-cover (e.g. ~96-98% for nominal 90%), because the relevance factor phi is common to numerator and denominator and is supposed to CANCEL in the ratio — freezing the denominator leaves that nuisance variability in; with a WEAK proxy the bands come out TOO NARROW and under-cover, because the ratio's heavy tails and sign flips are absent. Under Hall intervals the bands are additionally mis-centered because E*[b*] no longer reflects the ratio's skew.

3. AD-HOC SIGN FIXING ACROSS DRAWS (forcing sign(gamma*[norm_var]) or the sign of a chosen response to match the point estimate, or discarding 'wrong-sign' draws). Symptom: a genuinely bimodal rho* distribution truncated on one side; bands visibly narrower than the true sampling distribution; MC coverage ~70-80% for nominal 90%, worst for variables whose true response is near zero; the deficit does not shrink with B but does shrink as instrument strength rises, which makes it easy to miss if the MC only uses a strong instrument.

4. SILENTLY DROPPING FAILED DRAWS (near-zero gamma*[norm_var], too-few finite proxy obs). Symptom: the very draws with the largest |rho*| are removed, so interval width is systematically too small; under-coverage that worsens monotonically as the instrument weakens; and the count of draws used differs from B — assert n_used == B - n_failed and expose n_failed so this is visible rather than inferred.

5. NO CENTERING OF THE RESAMPLED RESIDUALS. Symptom: E*[u*_t] != 0 by an end-effect term, which in the recursive design acts as a spurious intercept/drift in y*, biasing the reestimated deterministic terms and the persistence in EVERY draw; the whole bootstrap IRF distribution shifts, so Hall intervals are mis-centered and coverage degrades systematically, worse at longer horizons and worse for larger ell. Exact test (no Monte Carlo needed): enumerate all T-ell+1 candidate blocks and compute E*[u*_t] analytically; it must be 0 to ~1e-14. Also verify the uncentered version of that same enumeration is nonzero, so you know the test has teeth.

6. CENTERING BY THE GRAND MEAN OF uhat INSTEAD OF THE POSITION-SPECIFIC MEANS ubar_s. This is the most likely centering bug because it looks right and is a silent no-op: sum_t uhat_t = 0 by OLS with a constant, so subtracting the grand mean changes nothing. Symptom: identical to no centering at all; the enumeration test above fails while every other output looks plausible. This bug ships unless the enumeration test exists.

7. FIXED-DESIGN SHORTCUT — computing gamma* = mean(m*_t u*_t) directly from the resampled pairs with Ahat and Psihat held at their point values, skipping the reconstruct-and-reestimate steps. Symptom: coverage is roughly right at h = 0 and then decays monotonically with horizon (e.g. ~88% at h = 0 falling to ~55-65% by h = 20 for nominal 90%), because all reduced-form coefficient uncertainty is missing; the decay steepens with the VAR's persistence and with p. Very easy to spot in a coverage-versus-horizon plot.

8. USING THE WILD BOOTSTRAP AT ALL (the Mertens–Ravn 2013 / Gertler–Karadi 2015 default). With a common Rademacher multiplier e_t in {-1,+1} applied to both blocks — u*_t = e_t uhat_t, m*_t = e_t m_t — the product is m*_t u*_t' = e_t^2 m_t uhat_t' = m_t uhat_t' POINTWISE, so sum_t m*_t u*_t' is bit-identical in every draw. Assert this in a test and you will see it. The identifying moment therefore carries essentially no bootstrap variability (only the second-order wedge between u*_t and the reestimated uhat*_t), so the identification step's sampling uncertainty is missing. Symptoms: bands far too SHORT — under-coverage at every horizon, and the deficit does NOT vanish as T grows (it is a first-order failure, not a finite-sample one). It is most severe where the identification step dominates the total variance (impact and short horizons); because the frozen 1/gamma*[norm_var] scale multiplies the coefficient uncertainty at all horizons, the ABSOLUTE width shortfall keeps growing with h in persistent systems even where the relative shortfall shrinks. In the JL replication of Mertens–Ravn this is what flips significant findings to insignificant. VARIANT: Rademacher applied to uhat only with m held fixed — then sum_t m_t u*_t' does vary, but with the variance implied by cross-sectional independence and the Rademacher's imposed symmetric fourth moments; it still fails to replicate serial dependence in the products m_t u_t' (volatility clustering, proxy persistence), so it still under-covers whenever those autocovariances are positive, which is the empirically typical case.

9. NON-OVERLAPPING BLOCKS — drawing from the floor(T/ell) disjoint blocks instead of the T-ell+1 overlapping candidates. Symptom: drastically fewer distinct blocks, so the bootstrap distribution is lumpy and discrete; band endpoints jump discontinuously as ell changes by one; coverage is erratic and typically too low at moderate T. The ell-sensitivity plot from Step 13 is jagged instead of smooth.

10. SILENTLY SUBSTITUTING THE CIRCULAR BLOCK BOOTSTRAP (wrap-around) while keeping the position-wise centering. The two prescriptions do not compose — under the CBB every observation appears in exactly ell blocks and grand-mean centering is the correct fix, so mixing them re-introduces a mean bias. Symptom: bands change when you rotate the sample's start date by a few observations, more than resampling noise can account for; and with a trending or regime-shifting proxy the splice of t = T to t = 1 inflates the variance.

11. BLOCK LENGTH NOT GROWING WITH T (a hardcoded ell, e.g. 4 or 8). Symptom: coverage does not converge to nominal as T grows — it PLATEAUS below nominal, because serial dependence beyond lag ell is never captured, and the plateau level depends on the DGP's dependence. Invisible if the MC uses a single T; run T = 200 / 500 / 2000 and look for the plateau instead of a monotone approach to nominal.

12. WRONG BOOTSTRAP SAMPLE LENGTH — building only floor(T/ell) blocks, or keeping all N*ell observations instead of truncating to exactly T. Symptom: the bootstrap distribution is scaled by the wrong sqrt(T), producing a width bias of roughly sqrt(T/(N*ell)); this shows up as a persistent 1-3 percentage-point coverage offset that does not shrink as B grows (so it cannot be mistaken for Monte Carlo error).

13. EFRON PERCENTILE WHERE THE BOOTSTRAP DISTRIBUTION IS SKEWED OR OFF-CENTER. Symptom: percentile intervals shift WITH the bias instead of against it, so total two-sided coverage can look near-nominal while the one-sided coverage is badly asymmetric — the true value falls below the lower bound far more often than above the upper (or vice versa). Report LEFT and RIGHT non-coverage separately in the MC, not just the two-sided total, or this is invisible.

14. PROXY NaN HANDLING THAT COMPACTS THE SERIES. Dropping NaN proxy entries by re-indexing (so the finite proxy values are packed into positions 1..|O|) destroys the date alignment with uhat*, and the failure mode is identical to independent resampling: gamma* -> 0, F* -> 1, absurd bands. Symptom test: a proxy with a NaN prefix must produce the same bands whether the unavailable region is coded NaN or masked by an explicit index set.

15. REUSING THE SAME RNG STREAM PER DRAW, OR DRAWING BLOCK STARTS WITHOUT REPLACEMENT. Symptom: duplicated or over-dispersed-then-collapsing draws; with sampling without replacement and small N the band width shrinks toward zero as B grows instead of converging.

### Flagged uncertain — verify before asserting in user-facing docs

1. EXACT FORM OF JL'S PROXY RESCALING. I recall that JL apply a deterministic scale adjustment to the resampled proxy in addition to the position-wise centering, but I cannot state its algebraic form and will not guess a constant. MITIGATION AND WHY THIS IS SAFE TO SHIP AROUND: multiplying the whole bootstrap proxy by any positive scalar leaves rho* = gamma*_j/gamma*_{norm} exactly invariant, so no choice here can move the IRF bands — only the reported F* and reliability*. Pin it from JL (2019) AER appendix + the AER data/code archive before documenting it as implemented.

2. BLOCK-LENGTH RULE. I believe JL use ell = 5.03 * T^{1/4} (rounded), which for the Mertens–Ravn quarterly sample T ~ 225 gives ell ~ 19-20, and the number 19 or 20 does ring true for their application. Moderate confidence on the constant 5.03, and on T^{1/4} rather than T^{1/3} or T^{1/5}. Also unverified: whether they round, ceil, or floor. Verify before hardcoding the default; the required RATE (ell -> inf, ell/T -> 0) is not in doubt.

3. INTERVAL TYPE. I believe JL recommend Hall's percentile (basic/reverse-percentile) interval and explicitly note it differs from the plain Efron percentile method that Mertens–Ravn / Gertler–Karadi report, on the grounds that block-bootstrap draws are not centered at the point estimate. Moderate confidence. Returning both (as the output contract does) removes the risk of shipping the wrong default silently.

4. WHETHER JL CENTER THE PROXY POSITION-WISE TOO. High confidence that the RESIDUALS get position-wise centering; lower confidence that JL apply the identical treatment to m_t. Low stakes: a constant shift of m* is annihilated by the moment (the reestimated residuals sum to zero), so only the position-DEPENDENT part of the centering can matter, and it is an O(ell/T) end effect.

5. HORIZON PROFILE OF THE WILD BOOTSTRAP'S UNDER-COVERAGE. The DIRECTION is unambiguous (intervals too short, under-coverage, not vanishing in T). Whether measured coverage worsens or improves with horizon is DGP-dependent: the frozen 1/gamma*[norm_var] scale multiplies coefficient uncertainty at every horizon so the absolute width shortfall grows with h in persistent systems, while the relative shortfall typically shrinks because Psi_h(Ahat*) contributes genuine variability at long h. I will not claim a universal direction — measure it in the MC and report what you find.

6. INITIAL CONDITIONS. High-ish confidence (inherited from Brüggemann–Jentsch–Trenkler 2016) that the p presample rows are fixed at the ACTUAL observed values with no burn-in; not independently verified against JL's own text.

7. BLOCK COUNT AND TRUNCATION. High-ish confidence that N = ceil(T/ell) blocks are laid end to end and the concatenation is truncated to exactly T; not verified whether JL instead retain all N*ell observations. The choice is small but not free (it rescales the bootstrap distribution by sqrt(T/(N*ell))), so verify.

8. WHETHER JL SCREEN EXPLOSIVE Ahat* DRAWS. I believe they do not, but this is inference from the design rather than something I read.

9. MULTI-INSTRUMENT (k > 1) NORMALIZATION. ## B. Weak-instrument-robust sets (Montiel Olea-Stock-Watson)

**Method.** Weak-instrument-robust (Anderson-Rubin / Fieller) confidence sets for proxy-SVAR impulse responses — one instrument, one target shock, unit-effect normalization

**Citation.** Montiel Olea, J. L., Stock, J. H., & Watson, M. W. (2021). "Inference in Structural Vector Autoregressions Identified with an External Instrument." Journal of Econometrics, 225(1), 74–87. Supporting/heritage: Anderson, T. W. & Rubin, H. (1949); Fieller, E. C. (1954), JRSS-B 16(2):175–185 (confidence sets for a ratio, of which this is an instance); Dufour, J.-M. (1997), Econometrica 65(6):1365–1387 (impossibility of bounded valid sets under possible non-identification); Staiger, D. & Stock, J. H. (1997), Econometrica 65(3):557–586 (weak-instrument asymptotics, F>10 rule of thumb); Stock, J. H. & Watson, M. W. (2018), Economic Journal 128(610):917–948 (SVAR-IV/LP-IV framing, reliability); Jentsch, C. & Lunsford, K. G. (2019), AER 109(7):2655–2678 (wild bootstrap invalid here; moving-block alternative); Montiel Olea, J. L. & Pflueger, C. (2013), JBES 31(3):358–369 (effective F). NOTE: the volume/page numbers for MOSW 2021 are from memory and were not verified from the paper in this session — check before printing in docs or CITATION.cff. The closed-form quadratic algebra below I derived here from the moment structure; I did not read MOSW to confirm they present it in this exact form (see `uncertain`).

**Stated confidence.** medium-high on the mathematics and the implementable algebra — the affine-null / quadratic-variance structure, the closed-form quadratic inversion, the four-case taxonomy, the cell-independence of A, the never-empty and single-point-at-(norm_var, h=0) results are all derived here from the moment structure in proxy.rs and are self-checkable against a grid; medium on attribution — I did not read Montiel Olea-Stock-Watson 2021 in this session, so which parts of the variance construction and presentation are theirs specifically versus the general AR/Fieller/Dufour literature is flagged in `uncertain`.

### Algorithm

1. SETUP (reuse the existing point-estimate path in /Users/chasecoleman/Time-Series-python/crates/tsecon-ident/src/proxy.rs). Inputs: residuals u (T x n), proxy m (length T, NaN = unavailable), MA sequence Psi_0..Psi_H with Psi_0 = I, norm_var k, unit scalar `unit`, confidence level 1-alpha. Overlap O = { t : m_t finite }, T_O = |O| = n_proxy. Demean m and every column of u over O (exactly as proxy.rs already does). gamma_hat_j = (1/T_O) * sum_{t in O} m~_t * u~_{jt}; this is the existing `cov_um`. Require gamma_hat_k != 0.

2. PARAMETER BEING BOUNDED. The object is the unit-effect-normalized structural IRF of variable i at horizon h, lambda_{i,h} = unit * (e_i' Psi_h gamma) / (e_k' gamma). Its point estimate is exactly the existing `irf[h][i]`. This is the ONLY inferential target available in the single-instrument case (the one-standard-deviation scale is not point-identified, per the module docs), and there is one confidence set per (h, i) cell — the sets are POINTWISE, not a joint band over h.

3. THE KEY STRUCTURAL FACT (why a closed form exists). H0: lambda_{i,h} = lam is equivalent to a restriction that is AFFINE in lam and LINEAR in gamma: a_{i,h}(lam)' gamma = 0 with a_{i,h}(lam) = unit * Psi_h' e_i - lam * e_k. So the null is the single moment condition E[ m_t * ( unit*e_i'Psi_h u_t - lam*e_k'u_t ) ] = 0 — literally 'the instrument is uncorrelated with this constructed linear combination of reduced-form innovations', i.e. an Anderson-Rubin moment. Nothing about lam enters nonlinearly.

4. BUILD THE MOMENT COVARIANCE ONCE. Form the T_O x n matrix G with rows g_t = m~_t * u~_t (so gamma_hat = mean_t g_t), and center it: g~_t = g_t - gamma_hat. Then Omega_hat = (1/T_O) * sum_{t in O} g~_t g~_t' is the HC0/White estimate of the asymptotic variance of sqrt(T_O)*(gamma_hat - gamma). This n x n matrix is computed ONCE and serves every (h,i) cell. HAC variant (use when m_t*u_t may be serially correlated, e.g. an aggregated proxy): Omega_hat = Gamma_0 + sum_{j=1..L} w_j (Gamma_j + Gamma_j') with Bartlett w_j = 1 - j/(L+1) and Gamma_j = (1/T_O) sum_{t>j} g~_t g~_{t-j}'. Bartlett is required (not a rectangular kernel) because the branch logic below assumes Omega_hat is PSD. Bootstrap variant: Omega_hat = T_O * Cov*(gamma_hat*) across Jentsch-Lunsford moving-block replications that jointly resample (u_t, m_t) in blocks and re-fit the VAR — this is the only variant that also picks up Psi_h estimation error. GUARD: assert Omega_hat PSD (Omega_hat[k,k] > 0 and, per cell, v_1^2 <= v_0*v_2 up to tolerance); if not, raise rather than return a set.

5. PER-CELL COEFFICIENTS (all closed form, no grid). Precompute P_h = Psi_h Omega_hat and Q_h = Psi_h Omega_hat Psi_h' once per horizon (O(n^3) per h). Then for each (h, i):  q1 = unit * e_i' Psi_h gamma_hat  (numerator moment),  q0 = gamma_hat_k  (denominator moment, SAME for all cells),  v_0 = unit^2 * Q_h[i,i],  v_1 = unit * P_h[i,k],  v_2 = Omega_hat[k,k] (SAME for all cells). Define g_hat(lam) = q1 - lam*q0 (affine) and V_hat(lam) = v_0 - 2*lam*v_1 + lam^2*v_2 = a(lam)' Omega_hat a(lam) (quadratic, >= 0 by PSD-ness). Total cost O(T_O*n^2 + (H+1)*n^3) — negligible.

6. THE STATISTIC. AR_{i,h}(lam) = T_O * g_hat(lam)^2 / V_hat(lam). This is (asymptotically) the squared heteroskedasticity-robust t-statistic for a zero coefficient on m_t in the regression of the constructed series w_t(lam) = unit*e_i'Psi_h u~_t - lam*u~_{kt} on m~_t, with the null IMPOSED in the variance (residual = w_t(lam) itself, not the fitted residual). Imposing the null is what makes V_hat depend on lam, and that lam-dependence is the whole source of the non-Wald behaviour below. Critical value c = chi2_{1, 1-alpha} = z_{1-alpha/2}^2 (c = 3.8415 at 95%). Optionally offer c = F_{1, T_O-2, 1-alpha} as a finite-sample flavour; document which is used.

7. INVERT IN CLOSED FORM. CS_{i,h} = { lam : AR(lam) <= c } = { lam : A*lam^2 + B*lam + C <= 0 } with  A = T_O*q0^2 - c*v_2,  B = 2*(c*v_1 - T_O*q1*q0),  C = T_O*q1^2 - c*v_0.  (Derivation: T_O(q1 - lam q0)^2 - c(v_0 - 2 lam v_1 + lam^2 v_2) <= 0, collect powers of lam.) NO GRID IS NEEDED. The closed form survives ANY variance estimator that is a quadratic polynomial in lam, which every valid one is — including the full joint delta-method variance that adds Psi_h uncertainty, because d(moment)/d(vec A_VAR) is proportional to gamma and carries no lam, contributing a constant to v_0 and an affine term to v_1.

8. ROOTS, NUMERICALLY STABLE. D = B^2 - 4*A*C. Do not use (-B +/- sqrt(D))/(2A) directly. Use s = -B - sign(B)*sqrt(D) (with sign(0) := +1), then r_a = s/(2A), r_b = 2C/s (Vieta), and sort so r_1 <= r_2. Branch to the linear case (next step) when |A| <= tau_A with a scale-aware tolerance, e.g. tau_A = 1e-12 * max(T_O*q0^2, c*v_2).

9. CASE LOGIC — the four (five with the point case) shapes.  (a) |A| <= tau_A (knife edge): degenerate to B*lam + C <= 0. If |B| <= tau_B: set = R when C <= 0, EMPTY when C > 0. If B > 0: set = (-inf, -C/B] (one half-line). If B < 0: set = [-C/B, +inf).  (b) A > 0 and D > 0: BOUNDED INTERVAL [r_1, r_2].  (c) A > 0 and D == 0 (within tolerance): the SINGLE POINT { -B/(2A) } — this is a valid nonempty set, NOT empty (it is exactly what the (i=k, h=0) cell produces; see step 12).  (d) A > 0 and D < 0: EMPTY. Unreachable in the just-identified single-instrument case (step 11) — treat a hit as an internal invariant violation and raise.  (e) A < 0 and D > 0: EXTERIOR — the UNION (-inf, r_1] u [r_2, +inf), two disjoint half-lines; the open middle (r_1, r_2) is what the data reject.  (f) A < 0 and D <= 0: THE WHOLE REAL LINE R (the quadratic is <= 0 everywhere).

10. THE BOUNDEDNESS SWITCH IS ONE SCALAR, SHARED BY THE ENTIRE GRID. A = T_O*gamma_hat_k^2 - c*Omega_hat[k,k] depends on NEITHER i NOR h. So define ar_bound_stat = T_O * gamma_hat_k^2 / Omega_hat[k,k] (a robust Wald statistic for H0: gamma_k = 0, i.e. a first-stage relevance test) and ar_bounded_all = (ar_bound_stat > c). Then: ar_bounded_all TRUE => every cell is a connected bounded interval (or the degenerate point); FALSE => every cell is an exterior-union or all of R; equal => every cell is a half-line. Weak identification is a property of the DENOMINATOR only, so you never get 'h=0 bounded, h=8 unbounded'. Assert this invariant in tests.

11. NEVER-EMPTY INVARIANT (state it in the docs). At lam_hat = q1/q0 we have g_hat = 0, so A*lam_hat^2 + B*lam_hat + C = -c*V_hat(lam_hat) <= 0: the point estimate is ALWAYS in the set. Hence with one instrument and one scalar parameter the set is never empty (and A > 0 forces D > 0). Emptiness can only arise from over-identification (more proxies than target shocks, where min_lam AR(lam) is a J-statistic), from a degenerate V_hat(lam_hat) = 0, or from a caller intersecting sets across horizons. Keep EMPTY in the contract for those futures, but do not advertise it as a normal outcome of the 1x1 case.

12. DEGENERATE CELL THAT MUST NOT CRASH. For i = k, h = 0: Psi_0 = I gives q1 = unit*gamma_hat_k, q0 = gamma_hat_k, v_0 = unit^2*Omega_hat[k,k], v_1 = unit*Omega_hat[k,k], v_2 = Omega_hat[k,k], hence A*lam^2+B*lam+C = A*(lam - unit)^2 and D = 0 EXACTLY. Correct answer: the single point { unit } when ar_bounded_all, else all of R. A naive 'A>0 and D<=0 => EMPTY' branch reports EMPTY for the impact response of the normalizing variable — a visible, embarrassing bug. Also note AR(unit) = 0/0 there, so any grid-based fallback must not evaluate the ratio at that point.

13. ZERO-EXCLUSION, WHICH SURVIVES WEAK IDENTIFICATION. 0 in CS <=> C <= 0 <=> T_O*q1^2 <= c*v_0, a robust test that the numerator moment unit*e_i'Psi_h gamma is zero. Return ci_excludes_zero = (C > 0) per cell. This is the one substantive statement (is the response nonzero, and of what sign) that remains informative when the set is R or a union of rays; the magnitude question is the one that dies. Document that.

14. OPTIONAL FREE EXTENSIONS, same machinery: (i) CUMULATIVE IRFs — replace Psi_h by sum_{s<=h} Psi_s (still linear in gamma, so the identical quadratic applies); (ii) any ratio of two linear functionals of gamma (e.g. a multiplier = IRF at h1 over IRF at h2, or `relative_impact` = the h=0 cells); (iii) nested levels — the 90% set is contained in the 95% set contained in the 99% set, exactly, because only c moves.

15. ALSO RETURN AN EVALUATOR. Expose ar_quad = (A, B, C) per cell so callers can re-derive the set, evaluate AR(lam) anywhere, intersect sets across horizons, or grid it themselves. This makes the output auditable and is what the validation grid-test consumes.

### What a wrong implementation does (these become tests)

1. USES A lam-INDEPENDENT VARIANCE (delta method frozen at lam_hat, or a bootstrap SD of lam_hat). Then AR(lam) <= c reduces to a symmetric bounded interval lam_hat +/- z*se and you have silently reimplemented the Wald set you were trying to escape. SYMPTOM: ci_bounded is True in 100% of replications including the weak arm; the EXTERIOR and R cases never appear; the interval is exactly symmetric about lam_hat (a genuine AR set is asymmetric except in the degenerate i=k,h=0 cell). This is the single most likely wrong implementation and the coverage harness will NOT catch it in a strong-instrument arm.

2. REPORTS THE EXTERIOR CASE (A<0, D>0) AS A PLAIN [lower, upper] INTERVAL. The caller then shades exactly the region the data REJECT, and the plot looks completely normal — a wide-ish band with the point estimate possibly outside it. SYMPTOM: in the weak arm, measured coverage collapses toward alpha instead of rising toward 1, and lam_hat lies outside its own 'interval' in a large fraction of reps. The ci_kind flag is the only thing that prevents this; a (lower, upper) pair alone CANNOT express it.

3. TREATS A>0 with D<=0 AS EMPTY. Fires deterministically on the (i=norm_var, h=0) cell, where D == 0 exactly and the true set is the single point {unit}. SYMPTOM: the entire impact row of the normalizing variable comes back NaN/empty while every other cell looks fine; users report 'the confidence set for the variable I normalized on is empty'.

4. ORDERS THE ROOTS WITH (-B +/- sqrt(D))/(2A) WITHOUT ACCOUNTING FOR sign(A). When A<0 the '+sqrt(D)' root is the SMALLER one, so lower > upper is returned silently. SYMPTOM: a membership test coded as lower <= truth <= upper is then always False, and weak-arm coverage measures ~0.00 instead of ~1.00 — which looks like a coverage catastrophe rather than a root-ordering typo.

5. SOLVES THE QUADRATIC NAIVELY NEAR A ~ 0. As ar_bound_stat approaches c from above, A -> 0+ and the endpoints diverge like 1/A; the textbook formula suffers catastrophic cancellation in -B + sqrt(D). SYMPTOM: endpoints of magnitude 1e12-1e16 that flip sign between adjacent horizons, or one endpoint exactly 0.0 (from the cancelling branch) that a reader interprets as 'the response is bounded away from zero on one side'. Fix with the Vieta pair r_b = 2C/s.

6. CLAMPS +/-inf TO A FINITE SENTINEL inside the library (+/-1e10, or the plot's axis limits, or np.nan_to_num). SYMPTOM: everything looks finite and well-behaved; ci_bounded is meaningless; the weak arm shows 'nominal coverage with a wide interval' and the reader is never told that no bounded honest set exists. This destroys the entire point of the method while leaving every test green.

7. USES T (the full residual sample) INSTEAD OF T_O (the overlap count) IN THE AR SCALING, or divides Omega_hat by T while gamma_hat averaged over T_O. The set shrinks by a factor sqrt(T/T_O). SYMPTOM: coverage degrades monotonically as the NaN fraction of the proxy rises — 0.95 with a full proxy, 0.88 with 40% missing. Exact test: prepending NaNs to the proxy (with the corresponding rows genuinely uninformative) must leave the set bit-identical to running on the truncated sample.

8. DOES NOT IMPOSE THE NULL IN THE VARIANCE (uses the fitted first-stage residual of w_t(lam) on m_t, or centers on the unrestricted estimate). Asymptotically equivalent, but the algebraic guarantees break: lam_hat is no longer certain to be in the set, the 'bounded <=> relevance statistic > c' equivalence fails, and A stops being cell-independent. SYMPTOM: the assert 'lam_hat in CS' fails on a few percent of random datasets; different horizons disagree about boundedness.

9. OMITS THE Psi_h ESTIMATION ERROR (the recommended default) WITHOUT DISCLOSING IT. Valid under weak-instrument (local-to-zero relevance) asymptotics because that variance term enters multiplied by gamma, but it is a genuine O(T^{-1/2}) omission when the instrument is strong. SYMPTOM: in the STRONG-instrument arm, coverage is at nominal at h=0 and falls below it as h grows (e.g. 0.95 at h=0, 0.91 at h=12), worse at small T and larger lag order. This is the honest cost of the simple variance and must be measured and printed, not discovered by a user.

10. INCLUDES A Psi_h VARIANCE TERM THAT DOES NOT VANISH WITH gamma (e.g. adds avar(vec Psi_h) scaled by the NORMALIZED impact b instead of by the raw gamma). The set stops being weak-IV-robust: it stays bounded under weak instruments and loses exact similarity. SYMPTOM: in the weak arm, the unbounded fraction stays near zero and coverage drifts off nominal in whichever direction the extra term pushes; the flat coverage-vs-F curve bends.

11. USES A NON-PSD HAC (rectangular/truncated kernel, or a bandwidth that makes v_1^2 > v_0*v_2). Then V_hat(lam) can go negative, AR(lam) <= c is no longer a quadratic-set problem, and the branch logic produces nonsense (an 'interval' where the statistic is negative). SYMPTOM: sets that violate the nesting property (the 90% set not contained in the 95% set), or a cell where ci_excludes_zero is True while 0 lies inside the reported interval.

12. USES THE WRONG CRITICAL VALUE. chi2 with n or H+1 degrees of freedom (multiplicity confusion) gives absurdly wide pointwise sets and 100% coverage everywhere; using z instead of z^2 gives c = 1.96 instead of 3.84 and roughly 83% coverage in the strong arm. SYMPTOM for the latter: strong-arm coverage lands near 0.83 uniformly across horizons — a flat shortfall is the signature of a critical-value bug, as opposed to the horizon-increasing shortfall of the omitted-Psi bug.

13. DOCUMENTS 'BOUNDED IFF first_stage_f > c' USING THE EXISTING HC1 F. proxy.rs's first_stage_f uses a residual-based HC1 meat (sum m~^2 e^2 with dof scaling); the boundedness statistic is T_O*gamma_k^2/Omega[k,k] = S_my^2 / sum(m~*u~_k - gamma_k)^2. These are asymptotically equivalent but numerically different. SYMPTOM: a user with first_stage_f = 3.90 gets an unbounded set and files a bug against the documentation. Return both numbers and state the rule only in terms of ar_bound_stat.

14. CONFLATES 'BOUNDED' WITH 'STRONG'. The boundedness threshold at 95% is c = 3.84, not 10. SYMPTOM (a reasoning bug, not a code bug): a paper reports a tidy bounded AR interval from an instrument with F = 4.5 and readers conclude identification was fine. The set is honest; the instrument is not. Print first_stage_f adjacent to every set and say that a bounded AR set certifies only F > 3.84.

15. MISALIGNS THE NaN DROP — filters m but not the matching rows of u, or drops NaNs after computing the means. SYMPTOM: first_stage_f looks healthy while the set drifts as the NaN prefix length changes; gamma_hat_k moves when leading NaNs are added. The existing overlap logic in proxy.rs is correct; the new code must reuse it rather than re-deriving it.

16. APPLIES `unit` INCONSISTENTLY (folds it into q1 but not into v_0/v_1, or applies it twice). SYMPTOM: the set is not equivariant to `unit` — running with unit=2.0 does not give exactly twice the set of unit=1.0. Cheap exact property test.

17. REPORTS A SCALAR SUMMARY WIDTH (mean width across horizons, or a 'median band width' in the printed summary) WITHOUT inf-AWARENESS. SYMPTOM: nan/inf in the summary table, or np.mean over an array containing +inf silently returning inf and being formatted as 'inf' in a docs example. In the weak arm the mean width is meaningless even when finite; the informative finite statistic is the length of the EXCLUDED middle (r_2 - r_1) for exterior sets.

18. PRESENTS THE POINTWISE SETS AS A JOINT BAND over the horizon path. SYMPTOM: the joint (simultaneous) coverage of the whole IRF path is far below nominal — the repo's own 'pointwise is not joint' analysis measured 90% pointwise as 72% joint for var_irf_bands. Not a bug in the set, but a documentation defect that must be stated where the set is returned.

19. OFFERS A PERCENTILE BOOTSTRAP OF lam_hat AS THE 'ROBUST' OPTION. A percentile bootstrap of a ratio with a near-zero denominator is invalid under weak instruments (and the wild bootstrap is inconsistent for proxy SVARs at all — Jentsch-Lunsford 2019). SYMPTOM: bounded, plausible-looking intervals in the weak arm with coverage well below nominal. The bootstrap's only legitimate role here is estimating Omega_hat (the moment covariance), which preserves the closed form.
