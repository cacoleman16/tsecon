# Repo audit — claims-versus-reality probes

Probe scripts for the claims sweep of the whole-repository audit
(`docs/roadmap/27-repo-audit-2026-09/claims.md`). All run from the repository root
with the release extension built into the sweep's venv.

| script | what it checks |
|---|---|
| `common.py` | shared helpers: the audited doc set, the wheel's public surface, fenced-block extraction |
| `registry_ext.py` | the round-11 canonical-input registry plus the eleven 0.8.0 ML callables |
| `collect_keys.py` | calls every public callable on its registry input and records the returned keys and parameter list (`out/returned_keys.json`) |
| `sweep_names.py` | every backticked identifier and `tsecon.<name>` mention in the doc set, classified against the surface and the returned keys (`out/sweep_names.json`, `out/sweep_names_review.md`) |
| `probe_phantoms.py` | second pass over the names sweep: returned-key claims that only hold under a non-default mode |
| `sweep_exec.py` + `exec_runner.py` | runs every fenced `python` block on the README, index, quickstart, cookbook, guide and model cards; compares pasted output (`out/sweep_exec.json`, `out/sweep_exec_recheck.json`) |
| `sweep_denials.py` | every "not implemented / roadmap / does not ship" sentence checked against the wheel |
| `sweep_changelog.py` | every 0.6.0–0.8.0 CHANGELOG bullet that names a function or behaviour, verified on the wheel |
| `sweep_paper.py` | every quantitative claim and citation in `paper/paper.md` recomputed or resolved |
| `sweep_counts.sh` | recomputes every count the repository states about itself with the repo's own rules (`out/sweep_counts.txt`) |

Outputs land in `out/`. The review markdown, the recheck JSON, the returned
keys and the count listing are committed; `sweep_names.json` (3 MB) and
`sweep_exec.json` (200 KB) are regenerated by the scripts and are not.
