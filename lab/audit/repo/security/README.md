# Repo audit — security probes

Probe scripts for the security sweep of the whole-repository audit
(`docs/roadmap/27-repo-audit-2026-09/security.md`). All run from the
repository root with the release extension built into the sweep's venv.

| script | what it does |
|---|---|
| `registry_ml.py` | canonical valid inputs for all 173 public callables (the round-11 registry plus the 0.8.0 wave) |
| `sweep_adversarial.py` | the adversarial-input matrix: from each callable's canonical call, every integer, float and array argument mutated through the hostile set (huge counts, 2^31, 2^63, NaN, ∞, empty, 1×1, zero columns, wrong types), each cell in a subprocess with a wall-clock cap; classifies refusal / normal return / `PanicException` / abort / hang |
| `probe_callbacks.py` | the three Python callback bridges under hostile or broken callables (raising, returning junk, re-entrancy, `KeyboardInterrupt`) |
| `probe_import_network.py` | does `import tsecon` (or a representative call) open a socket, read an environment variable, or touch the filesystem outside the package (`strace` network and file traces) |
| `scan_history.sh` | credential-pattern scan over every ref, every commit's full patch text, and dangling blobs |
| `check_wheel.py` | does the built wheel ship exactly the package and nothing else; SBOM path leakage |

Outputs land in `out/`. The per-matrix markdown summaries, the pass logs
(committed as `.txt` because `*.log` is ignored repo-wide), the strace
traces and the SBOM path listing are committed; the two 1.3 MB per-cell
`.jsonl` records are regenerated by `sweep_adversarial.py` and are not.
